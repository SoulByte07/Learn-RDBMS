# scripts
> Python package for small relational database learning utilities.

`scripts` is a lightweight Python package for people practicing SQL and RDBMS workflows. It provides a simple place to keep helper scripts and repeatable data tasks while you learn. The goal is to make local experimentation faster and easier to maintain.

## Installation

```bash
pip install PKG
# or install from source
pip install "git+https://github.com/USER/REPO.git"
```

## Usage

```python
from PKG import run_example

result = run_example()
print(result)  # Expected output: "ok"
```
